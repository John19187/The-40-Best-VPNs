# 开源维护方法

本项目持续维护服务商资料、入口链接和更新记录，并通过结构化数据与自动检查降低过期
信息的影响。

## 数据维护

`data/providers.yml` 是 README 服务商清单的结构化索引，记录名称、对应标题和当前入口。
更新服务商信息时，应同时核对 README 与结构化清单，保持名称和链接一致。

信息更新优先参考：

1. 服务商官网、状态页或正式公告；
2. 可核查的 GitHub Issue 与 Pull Request；
3. 有明确时间和来源的社区反馈。

## 链接检查

`scripts/check_links.py` 定期检查结构化清单中的网址，并把结果写入
`.artifacts/link-check.json`。检查流程包括：

1. 请求当前入口并跟随标准重定向；
2. 记录最终网址、HTTP 状态码和响应时间；
3. 区分正常响应、访问限制、失效链接和临时网络错误；
4. 由维护者结合实际情况更新 README 与服务商清单。

GitHub Actions 在相关修改、手动触发和每周计划任务中运行数据校验与链接检查，并保存
检查报告，便于后续维护。

## 社区纠错

欢迎通过 Issue 或 Pull Request 提交服务商名称、入口、套餐与状态更新。提交时请写明
修改位置和公开来源，不要包含账号、订阅地址、节点凭据、个人 IP 或付款信息。

重大更新记录在 README 更新日志中，确保项目维护过程可追踪。
